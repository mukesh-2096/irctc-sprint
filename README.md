# irctc-sprint

This repository contains the research, problem statements, and design proposals for improving the IRCTC booking experience.

## Repository Contents

- `part-a/PROBLEMS.md`: documented user problems discovered during the IRCTC exploration.
- `part-b/AI-FEATURE.md`: proposed AI-powered waitlist confirmation predictor.
- `part-b/MATRIX.md`: impact vs effort comparison of the proposed features.
- `part-b/SPECS.md`: feature specifications for the design sprint solutions.
- `assets/screenshots/`: reference screenshots captured during exploration.
- `wireframes/`: UI wireframes and layout concepts for the proposed experience.
